aiTransform and PK Hosting: Accessibility, Responsive and Cross-Browser Audit

Task TPT-2026-03078, 4 pts, due 11 November 2026. Standard: WCAG 2.1 AA. Checked 6 November 2026. Public pages only. No forms submitted, no logins, no load testing, no security testing.

13 bugs found8 Medium5 Low0 High

Result in one line

13 bugs in total, all Medium or Low, none High. aiTransform carries 9 of them (5 from the automated checks, 4 from the live checks). PK Hosting passed every automated check on all 3 pages, and its 4 live bugs are all Low except one Medium (a repeated billing toggle). Mobile layout, 200 percent zoom, Firefox, and Safari were not testable in this environment and are listed as not run, not as passes.

Method

Automated checks: a Python checker (automation/auto_checks.py) ran on saved HTML copies of all 6 pages, covering lang, title, viewport, alt text, input labels, heading order, link and button names, duplicate ids, and inline-style contrast only. Results in automation/auto_results.json.

Live checks: a Chromium browser session at desktop size, checking keyboard navigation, visible focus, contrast by eye, layout, and the mobile menu control in the DOM. Desktop size was 1919x998, not the requested 1440x900, because the browser cannot set a viewport size.

Not run: mobile 390x844 (no device emulation), zoom to 200 percent (the browser showed no change when zoom was applied), Firefox and Safari (not available here), console errors (not read).

What passed

  • html lang attribute: pass on all 6 pages (aiTransform en, PK Hosting en-PK).
  • Page titles: present, non-empty, unique on all 6 pages.
  • Viewport meta: present on all 6 pages.
  • Images with alt text: 0 missing alt across all 6 pages (automated check).
  • Form inputs labelled: pass on all 6 pages.
  • Exactly one h1 per page: pass on all 6 pages.
  • Keyboard focus: visible with a logical order on the 4 pages checked live (aiTransform home and Image Generator tab: black outline; PK Hosting home and pricing: green outline).
  • PK Hosting skip-to-content link: present on home and pricing.
  • PK Hosting contrast: generally good (white on dark-green buttons, black body text on white).
  • PK Hosting pricing tables: proper column and row headers.

What was not verified

These are listed as not run, never as passes. They need a different environment: a browser with device emulation and working zoom, plus Firefox and Safari.

  • Mobile 390x844 layout, navigation, tap targets, and overflow on all 6 pages.
  • Zoom to 200 percent and text resize on all 6 pages.
  • Firefox and Safari rendering on all 6 pages.
  • B4 and B5 live check: whether JavaScript fills the empty call-to-action label on aiTransform blog and terms.
  • Console errors on all 6 pages.
  • Stylesheet colour contrast ratios: all text colours come from external CSS, so no ratio was measured for any stylesheet colour. The automated checker scored inline styles only (0 elements had a known inline background).
